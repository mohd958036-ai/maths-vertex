### Change Colors
Edit in `css/styles.css`:
```css

    --primary-dark: #0A1F44;      /* Main dark blue */
    --accent-gold: #D4AF37;       /* Gold accent */
    --text-light: #FFFFFF;        /* White text */
    --text-muted: #B0B0B0;        /* Gray text */
}
```
